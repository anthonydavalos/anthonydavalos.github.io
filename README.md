# Anthony Davalos - Portafolio profesional

Repositorio público del portafolio profesional de Anthony Davalos.

El sitio reunirá experiencia en ingeniería de software, automatización,
sistemas en tiempo real, trayectoria cuantitativa y formación en
ciberseguridad defensiva.

## Base técnica

- Astro
- TypeScript
- Bootstrap
- Sitio estático publicado con GitHub Pages

## Desarrollo

La implementación funcional se realizará de forma incremental mediante ramas
de trabajo y revisiones antes de integrar cambios en `main`.
