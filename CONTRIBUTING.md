# Contribución

## Flujo de trabajo

1. Crea una rama con un nombre descriptivo desde `main`.
2. Mantén los cambios enfocados y utiliza mensajes de commit convencionales.
3. Ejecuta `npm run quality` y `npm run security` antes de abrir una solicitud
   de cambios.
4. No incluyas credenciales, archivos de entorno, documentos personales ni
   material de referencia privado.
5. Solicita revisión antes de integrar cambios en `main`; no realices
   sobrescrituras forzadas del historial.

## Comprobaciones

- `npm run format:check` revisa el formato.
- `npm run lint` revisa el código.
- `npm run check` valida Astro y TypeScript.
- `npm run build` genera el sitio estático.
- `npm run verify:licenses` comprueba la licencia y los avisos de terceros.
- `npm run verify:pages` valida las rutas generadas y las rutas heredadas.
- `npm run security` revisa vulnerabilidades de dependencias de producción.

## Contenido profesional

- Publica únicamente afirmaciones respaldadas por una fuente identificable.
- Explica las discrepancias entre fuentes sin ocultarlas.
- Excluye información personal de contacto que no esté aprobada para difusión.
- Conserva los avisos y atribuciones exigidos por dependencias y recursos.
- Registra la procedencia, licencia y uso previsto de cada imagen antes de
  incorporarla al sitio público.

## Accesibilidad

Todo contenido debe ser navegable mediante teclado, mantener foco visible y
seguir siendo comprensible cuando JavaScript o las animaciones estén
deshabilitados.
