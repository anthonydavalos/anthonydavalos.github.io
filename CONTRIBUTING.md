# Contribución

## Flujo de trabajo

1. Crea una rama con un nombre descriptivo desde `main`.
2. Mantén los cambios enfocados y utiliza mensajes de commit convencionales.
3. Ejecuta las comprobaciones de formato, tipos, build, accesibilidad y
   licencias antes de abrir una solicitud de cambios.
4. No incluyas credenciales, archivos de entorno, documentos personales ni
   material de referencia privado.

## Contenido profesional

- Publica únicamente afirmaciones respaldadas por una fuente identificable.
- Explica las discrepancias entre fuentes sin ocultarlas.
- Excluye información personal de contacto que no esté aprobada para difusión.
- Conserva los avisos y atribuciones exigidos por dependencias y recursos.

## Accesibilidad

Todo contenido debe ser navegable mediante teclado, mantener foco visible y
seguir siendo comprensible cuando JavaScript o las animaciones estén
deshabilitados.
